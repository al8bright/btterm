## 3. 이번에 하지 않을 것으로 분류

- 시작 시 이전 탭 복원(F6.9, Should): U4 뒤 도그푸딩 이월 후보.
- 탭 닫기 확인·닫은 탭 다시 열기, 탭 복제·이름 변경: PRD에 없음. 제안으로만 남김.
- Shift+Enter 기록 즉시 실행: SEC-10(입력만)과 충돌하므로 제외.
- 파일 패널과 서버 목록 동시 표시(세로 분할): 사이드바 구조 변경이라 U3 이후 별도 검토.

## 4. 검토자 간 이견

- 모션 시간: 모션 120ms·200ms, 시각 140ms·180ms → 120ms(색)·200ms(이동·크기)로 통일.
- 서버 행 한 번 클릭: 흐름은 "선택, Enter·더블클릭=연결"로 통일 제안, 파워유저는 지금 방식이 일반적이라 문제 아님 → 현행 유지, 연결 버튼 노출만 U3에서 검토.
