| 항목 | 값 |
|---|---|
| 맥 대응 | OS 플래그(main → preload → renderer), Cmd 키맵·단축키 표기, 창(hiddenInset·신호등 92px·전체 화면 여백 제거), 메뉴(표준 역할만, SEC-8), 로컬 편집(실행 형식 차단·TextEdit), 맥 자동 업데이트 없음(M2-5) |

| 보안 리뷰 | 4회. 반영: 입력칸 Cmd+C/V가 먹히던 문제, 편집 메뉴 붙여넣기 정제 우회 차단, HTML·RTF TextEdit 렌더링 차단, 출시 빌드 `--use-mock-keychain`·`--password-store`면 비밀 저장 끔(SEC-2), hardened runtime(DYLD 주입 차단) |
| 테스트(맥) | 단위 885 · 통합 40 · E2E 37 모두 통과(`verify:full`). E2E 단축키는 OS 키맵에서 만든다 |
| 알게 된 것 | macOS 26 신호등은 약 79px까지 온다. CSS `display-mode: fullscreen`은 네이티브 전체 화면에서 맞지 않는다. `pnpm dev`와 패키징 앱은 같은 `@btterm/desktop Safe Storage` 키체인 항목을 쓰므로 서명이 바뀔 때마다 로그인 암호를 묻는다 |
| 남은 것 | 출시 빌드의 `--remote-debugging-port`·`--no-sandbox` 등은 남은 위험으로 둠(결정 M2-7), ad-hoc 서명 dylib 교체 위험(문서화), Windows에서 `pnpm verify` 회귀 확인, 손 확인(터미널 Cmd+V 한 번만·Cmd+W 탭 닫기·Cmd+Q) |
