# 2026-10-22 파일 전송 강화 · 키 생성 · 매일 쓰기 시작(설치 파일)

사용자 요청(2026-10-22): "파일 전송 강화 → 키 생성·공개키 등록 → 매일 쓰기 시작" 순서로 진행. E2E는 사용자가 다시 요청할 때까지 돌리지 않는다(단위·통합으로 검증).

| # | 결정 | 이유 |
|---|---|---|
| TR1 | **폴더째 전송**(F4.7, Should → 지금): 폴더를 고르면 대상에 같은 이름 폴더를 만들고(있으면 그 안에 합침) 안의 항목을 같은 배치로 큐에 넣는다. 링크·특수 파일은 따라가지 않고 건너뛴다. 깊이 32단계, 한 배치 1만 개 상한(넘으면 `too-many`). 다운로드는 이름마다 SEC-11 정규화 | 링크 순환·거대한 트리로 앱이 멈추지 않게 |
| TR2 | **이어받기**(F4.7): 업로드도 `.btterm-part`에 쓰고 끝나면 posix-rename으로 바꿔 넣는다(원본은 마지막까지 그대로). 실패하면 부분 파일을 남기고 전송 목록의 "다시 시도"가 그 지점부터 잇는다(같은 실행 동안). 취소는 지금처럼 부분 파일을 지운다(AC11). 앱을 끌 때 남은 부분 파일은 지운다 | 자동으로 이어 쓰면 다른 내용의 부분 파일에 붙일 위험. 사용자가 누른 재시도만 잇는다 |
| TR3 | **원격 파일 로컬 편집**(F4.8, Should → 지금): 파일 메뉴 "로컬에서 편집" → 앱 데이터 아래 임시 폴더로 받는다. 텍스트 허용 목록(.conf .json .yml .log .md 등)만 OS 기본 앱으로 열고, 나머지는 메모장으로 연다. 기본 동작은 .py·.sh를 실행할 수 있기 때문이다. 실행 가능한 확장자와 일반 파일이 아닌 것(폴더·링크)은 열지 않는다(SEC-11, 보안 리뷰 H1·M1). 남은 위험: 업로드 때 원격이 그사이 바뀌었는지 확인하지 않는다. 편집 중 원문이 userData/edit에 평문으로 남는다(다음 시작 때 지움). macOS 실행 형식 판단은 M2. 저장을 감지하면 "업로드할까요?"를 묻고 원자적으로 바꿔 넣는다. 자동 업로드는 하지 않는다. 탭을 닫으면 감시를 멈추고 임시 파일을 지운다. 확장자별 "Open with" 기억은 나중 | 덮어쓰기는 원격 파일을 바꾸는 일이라 확인 |
| TR4 | **키 쌍 생성**(F7.7, Polish → 지금): ed25519 기본, RSA 4096 선택, passphrase 선택. 생성은 session host(ssh2 `utils.generateKeyPair`, SEC: ssh2는 session host 전용). 개인키는 보관소에 저장하거나 파일로 내보내기. renderer는 공개키만 받는다(SEC-1). 생성은 한 번에 하나(bcrypt가 session host를 막음). 남은 위험: Windows에서 내보낸 파일은 고른 폴더의 ACL을 따른다(공유 폴더 주의), 암호 없는 키 내보내기 경고 없음 | |
| TR5 | **서버에 공개키 등록**(F7.8, Polish → 지금): 열린 세션의 SFTP로 `~/.ssh`(700)·`authorized_keys`(600)를 확인하고 중복이 없을 때만 한 줄 덧붙인다 | `ssh-copy-id` 대체. 기존 파일은 바꿔 넣지 않고 끝에 덧붙인다(동시 편집·교체 실패로 키가 사라지지 않게). 링크·쓰기 금지 파일은 건드리지 않는다. 남은 한계: AuthorizedKeysFile이 기본값이 아니면 다른 위치에 쓰고도 성공으로 알린다, SELinux 라벨은 맞추지 않는다 |
| TR6 | **알려진 호스트 관리**(F2.4b, Polish → 지금) + 호스트 키 교체(PLAN 남은 작업 #4): 목록·지문 보기·삭제. 불일치 경고창은 지금처럼 차단만(SEC-3, 우회 버튼 없음)하고 "알려진 호스트에서 이 키 지우기" 안내만 둔다. 지운 뒤 다시 연결하면 처음 보는 키로 확인받는다. 삭제 확인은 main의 시스템 확인창(기본 "취소")이 한다: renderer가 장악돼도 사용자 확인 없이 "지우기 → 재연결 → 수락"으로 불일치 차단을 넘을 수 없게(보안 리뷰 M-1). @revoked·@cert-authority 항목은 지우지 않는다 | 연결 창 안의 우회 경로를 만들지 않는다 |
| TR7 | **설치 파일(Windows NSIS).** 자동 업데이트(F5.6): 폐기(2026-11-26, [공개 범위](./2026-11-26-public-scope.md)). 설치는 새 설치 파일(NSIS)로 덮어 설치한다 | 매일 쓰기 시작 |
