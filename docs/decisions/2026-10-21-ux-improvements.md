| # | 결정 | 이유 |
|---|---|---|
| UX1 | 칸 크기 조절을 M2(F3.10)에서 M1(F3.10b)로 당긴다. 크기는 메모리에만 두고 저장·복원은 F3.10(M2) 그대로 | 분할(F3.10a)을 M1로 당겨 50:50 고정이 가장 큰 불편이 됨 |
| UX2 | 새 단축키: Ctrl+Shift+1~9(탭 번호), Ctrl+Alt+방향키(칸 포커스), Ctrl+Alt+Shift+방향키(칸 크기), Ctrl+Shift+D(같은 서버로 오른쪽 분할). Ctrl+Alt 계열은 칸이 2개 이상일 때만 가로챈다 | AGENTS §8 "Ctrl+Shift 계열" 원칙의 예외는 칸 조작 키뿐이고, 칸이 하나면 터미널로 보내 충돌을 줄인다. Windows Terminal의 Alt+방향키는 zsh·fish 단어 이동과 겹쳐 쓰지 않음 |
| UX3 | 빠른 연결 칸 = 저장된 서버 퍼지 검색 + `user@host`. 새 탭(+, Ctrl+Shift+T)은 이 목록을 연다. 명령 팔레트(F5.1b)는 M1.5 그대로 | 접속까지 단계를 줄이되 범위는 F5.1 안 |

| UX5 | 모달 공통 동작: 열 때 포커스 저장, 닫으면 복귀(없어졌으면 활성 터미널), Tab 가둠, 배경 `inert`, Esc=취소(호스트 키 창은 "연결 취소"). 모달이 열려 있으면 앱 단축키를 무시 | 포커스가 body로 떨어지는 문제(검토 B) |
| UX7 | 라이트 UI(F5.3)를 M1.5에서 M1로 당긴다(사용자 요청). 화면 모드 = 시스템(기본)·라이트·다크, 설정 `ui.theme`(선택 필드라 설정 파일 버전 유지). 터미널 테마와 분리 | 다크 고정이 불편하다는 요청. 토큰 이름은 그대로 두고 값만 바꿔 컴포넌트 수정 없이 적용 |
| UX8 | (2026-10-22) 도구 패널(디자인·명령 기록)을 창 오른쪽 끝에서 **활성 칸 안**으로 옮긴다. 액티비티 바의 도구 버튼은 없애고 칸 탭바의 [+] 옆 패널 버튼으로 연다(오른쪽 손잡이는 잘 안 보이고 탭 놓기와 겹쳐 2026-10-22 탭바로 옮김)(Ctrl+Shift+L·H 유지). 큰 영역 경계는 2px `--border-divider` | 사용자 요청. 디자인 "이 탭만"·명령 기록이 어느 탭 기준인지 위치로 드러난다. 분할 칸에서도 패널은 하나(활성 칸)만 |
| UX6 | 알림: 성공은 4초 뒤 자동으로 사라짐, 오류는 닫을 때까지 유지하고 `role=alert`. 사전에 없는 오류 코드는 일반 문구로 바꿔 코드를 노출하지 않는다 | 조용한 실패·코드 노출(검토 C) |
