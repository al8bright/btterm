# 2026-11-26 기능 정리와 저장소 공개 (범위 이동)

> **상태: 확정(2026-11-26, 사용자 결정).** PRD D15·D17·F5.6·F8·§6.2·§9.6·§10, PLAN, DESIGN §5.10, AGENTS §7·§9·§10, `docs/qa/ac-matrix.md`에 반영했다.

## 1. 결정

| # | 결정 | 이유 |
|---|---|---|
| PS1 | **자동 업데이트(F5.6)를 뺀다.** `electron-updater` 의존성, `UpdateService`, 배포 스크립트, 상태바 "다시 시작" 알림, `update.*` IPC. 설치는 새 NSIS 설치 파일로 덮어 설치한다 | 개인 도구에 업데이트 서버 운영이 필요 없다 |
| PS2 | **계정·동기화(F8 전체, Phase 2-S)를 뺀다.** 동기화 서버, core 동기화 암호·레코드·엔진, main 계정·동기화 서비스, 계정 대화상자, 마스터 비밀번호·자동 잠금·복구 키, 상태바 동기화 표시, 팔레트 계정·동기화 동작, `account.*`·`sync.*` IPC, `settings.changed` 이벤트 | PS1과 같다. 마스터 비밀번호·자동 잠금은 계정 전용이었다 |
| PS3 | 로컬 저장(서버 목록·설정·`safeStorage` 비밀 보관소)은 그대로 둔다. 예전 설정 파일에 남은 `accountLock`은 읽을 때 버린다(버전 유지) | 앱의 핵심 기능 |
| PS4 | PS1·PS2의 요구사항 문구는 PRD에 남기고 상태는 "제외"로 둔다(범위 밖, 나중에 다시 검토). AC36~AC40은 `excluded` | 다시 검토할 때 출발점 |
| PS5 | **저장소를 public으로 두고 MIT 라이선스를 붙인다.** 소스는 공개하고, 릴리스 바이너리는 본인 사용 전용이다. `main` 단일 브랜치·PR·CI 없음은 그대로(D15) | 사용자 결정 |
| PS6 | PRD §9.6 지식재산 전문가 검토: **소스 공개는 §9 클린룸 기록을 근거로 한 사용자 판단**으로 한다(전문가 검토 없음). 전문가 검토는 바이너리 공개 배포 전 조건으로 남긴다 | 법률 검토는 에이전트가 대신할 수 없다 |
| PS7 | 마스터 비밀번호(§6.2)는 F8과 함께 빠졌다. 소스 공개는 바이너리 배포가 아니므로 이 조건과 무관하고, 바이너리를 공개 배포하거나 여러 사람이 쓰기 전에는 다시 Must다 | §6.2 이견 기록 유지 |

## 2. 함께 한 일

- 의존성 제거: `electron-updater`(desktop). 추가한 의존성은 없다.
- 보안 리뷰 반영: 앱 시작 때 데이터 폴더와 `snapshots/*`에서 이전 버전의 계정·동기화 파일(`account.json`·`account-owner.json`·`account-kdf.json`·`sync-state.json`과 `.bak`)을 지운다(감싼 계정 키·토큰이 남지 않게). SEC-1 계약 테스트가 설정 스키마(`settings.get`·`update` 응답)도 검사하고, 검사기가 `catch`·`pipe`·`readonly`로 감싼 필드 안도 본다.
- 출시 빌드 디버깅·샌드박스 스위치 차단은 F8과 무관한 위험이라 결정 M2-7로 남는다.

## 3. 남은 것

- 자동 업데이트를 다시 검토한다면 HTTPS와 매니페스트 서명을 함께 정한다(업데이트 피드 중간자 위험).
- 바이너리를 공개 배포하려면 PRD §6.2(마스터 비밀번호)·§9.6(지식재산 검토)·§10(서명) 조건을 먼저 충족한다.
