# 2026-10-22 M1 마무리 + 일상 편의 기능 당김

사용자 요청(2026-10-22): "M1 마무리 → 일상 편의 묶음 → 탭 이름 바꾸기". 매일 쓰기 시작하는 데 필요한 기능을 M1.5·M2에서 지금으로 당긴다.

| # | 결정 | 이유 |
|---|---|---|
| DF1 | **M1 마무리**: 창 위치·크기·최대화 복원(F6.7), 탭 색(F3.1, `HostDefaults.tabColor` 상속), 확인창 경합(세션이 끝나면 그 세션의 확인창을 거둔다) | M1 종료 기준에 남은 항목. 확인창 경합은 2026-10-22 E2E 점검에서 찾은 알려진 문제 |
| DF2 | 창 상태는 `settings.json`의 선택 필드 `window`(bounds, maximized)에 main만 쓴다. renderer 요청으로는 바꿀 수 없다. 저장된 위치가 지금 연결된 화면 밖이면 기본 위치 | 모니터를 뗀 뒤 창이 화면 밖에 뜨는 문제 방지. 설정 파일 버전 유지(선택 필드) |
| DF3 | **탭 이름 바꾸기**(새 F3.1b): 탭 더블클릭·메뉴 "이름 바꾸기"·F2. 이 실행 동안만(저장하지 않음). 빈 이름이면 원래 이름 | 같은 서버 탭 여러 개(빌드·로그) 구분 |
| DF4 | **빈 화면 서버 카드**(새 F1.2b): 탭이 없는 칸에 고정 서버와 최근 접속 서버를 최대 8개 카드로. 누르면 접속 | 사이드바 최근 구역을 없앤 자리(2026-10-21)를 빈 화면이 맡는다 |
| DF5 | **연결 직후 명령**(F6.11, Polish → 지금): 서버·그룹 편집 고급 설정. 셸이 준비되면 1회 입력 + Enter. 가져온 값은 승인 전 비활성(SEC-12) | 기존 필드 `startupCommand` 활용 |
| DF6 | **명령 팔레트**(F5.1b, Polish → 지금): Ctrl+Shift+P. 앱 동작(키맵) + 서버 + 열린 탭을 한 목록에서 퍼지 검색, `>` 동작만, `#` 탭만 | 메뉴 없는 앱의 기능 찾기 입구 |
| DF7 | **스니펫**(F3.14, Should → 지금, 1단계): 도구 패널 "스니펫" 탭. 이름·명령·`{{변수}}` 입력, 입력만 / 실행. 설정 파일 `snippets`에 저장. production 태그 서버에서 `sudo` 포함 실행은 확인. "모든 탭에서 실행"(MultiExec)은 M2 그대로 | 자주 치는 명령. 패널 자리가 이미 있다 |
| DF8 | **재시작 시 탭 복원**(F6.9, Should → 지금): 종료 때 칸 배치와 탭(저장된 서버 = 프로필 id, 빠른 연결 = user@host:port)을 설정에 남기고, 다음 실행 때 빈 화면에 "이전 탭 N개 다시 열기" 버튼. 자동 재접속은 하지 않는다 | 비밀번호 재입력·확인 없이 연결하지 않게(재접속은 사용자 확인) |
| DF9 | 터미널 테마를 3종에서 9종으로(F3.16c 일부, Polish → 지금): Dracula · Solarized Dark · Gruvbox Dark(DESIGN §7에 이미 정한 값) + Solarized Light · Nord · Monokai. 원색 대비가 4.5 미만인 색은 xterm `minimumContrastRatio: 4.5`가 보정. 적용 범위 "이 서버/그룹"과 테마 가져오기는 그대로 M1.5 | 사용자 요청(2026-10-22: 많이 쓰는 테마로 9가지). 밝은 테마 2종(GitHub Light, Solarized Light) |
