# 서버 트리 끌어 놓기 (2026-10-21)

사용자 요청: "서버 및 폴더를 드래그 앤 드롭으로 폴더에 추가하거나 뺄 수 있어야 하고, 순번을 자유롭게 이동할 수 있어야 한다."
PRD에 없던 기능이라 F1.2a(M1)·AC35로 추가한다.

| # | 상황 | 결정 | 근거 |
|---|---|---|---|
| DND1 | 순서 모델 | 같은 부모 아래 그룹과 서버가 **한 순서**를 공유한다. `Profile.order`(선택 정수)를 더한다. 정렬은 `order`(없으면 맨 뒤) → 그룹 먼저 → 이름 | "순번을 자유롭게". 기존 파일은 order가 없어 지금과 같은 순서(그룹 먼저, 이름순)로 보인다 |
| DND2 | 스키마 | 선택 필드 추가라 기존 파일이 그대로 유효해 버전은 올리지 않는다(ST10과 같은 이유). 이전 앱으로 되돌려 저장하면 서버 순서(`Profile.order`)만 사라진다(그룹 순서는 남음) | 이전 앱이 새 파일을 거부하지 않게 |
| DND3 | 저장 | renderer는 `profiles.move`(대상, 새 부모, 위치)만 보내고 main이 core 순수 함수 `moveTreeItem`으로 형제 순서를 다시 매겨 한 번에 저장한다 | 여러 번 나눠 저장하면 중간에 실패할 때 순서가 깨진다 |
| DND4 | 거부 | 그룹을 자기 자신·하위로 옮기기, 없는 대상·부모는 변경 없이 무시한다 | 순환 방지 |
| DND5 | 상속 | 옮긴 서버는 새 그룹의 기본값을 물려받는다(재정의 값은 유지) | D13 상속 규칙 그대로 |
| DND7 | 상속 변화 확인(보안 리뷰 L1) | 옮기면 어떤 서버의 유효 `identityId`·`username`·`startupCommand`가 바뀌면 확인창(기본 버튼 "취소")을 띄운다. 순서만 바꾸는 이동은 묻지 않는다 | 실수로 놓아 다른 그룹의 인증 정보가 다른 호스트로 가거나 시작 명령이 실행되는 것 방지 |
| DND6 | 접근성 | M1은 마우스 끌기만. 키보드로 옮기기(예: Alt+↑↓)는 필요해지면 추가 | 범위 최소화 |
